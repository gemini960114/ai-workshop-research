## 00 Cloud vs. Local

Folder: `00-ai-workshop-openai/`

```text
What does "wet-lab science" in the title of this paper mean? Why would AI be used to handle laboratory work?
```


## 01 Getting Started with Antigravity

Folder: A new empty folder you create, e.g., `my-first-project`

**Install Essential Tools** (close and reopen Antigravity after installation)

```text
Please help me install Git, uv, and Node.js. Skip any that are already installed, tell me the reason if any fail, and finally list the version of each tool.
```

**Install Recommended Tools**

```text
Please help me install GitHub CLI, LibreOffice, and ffmpeg. Skip any that are already installed, tell me the reason if any fail, and finally list the version of each tool.
```

**Classroom Computers: Check Only, Do Not Install**

```text
Please tell me the installed versions of git, gh, uv, node, npm, ffmpeg, and LibreOffice (soffice) on this computer.
List any that cannot be found, and do not install them yet.
```

**First Web Page**

```text
Create a hello.html in this folder that displays "Hello Antigravity" and today's date in large text, then open it in the browser for me.
```

**Memory Match Game** (open another empty folder `my-second-project`)

```text
In this folder, help me build a "Memory Match" card game using the simplest Vite + JS setup:
16 cards arranged randomly; flip two matching cards to clear them, and show move count and timer at the top.
When all cards are cleared, display "Congratulations!" and a "Play Again" button.
Once finished, start the web server directly and give me the URL so I can click and play.
```

**Want to customize more?**: Try saying "Change the card faces to fruit icons", "Add a best score record", or "Change it to 20 cards"; when done playing, say "Stop the dev server".

**Appendix: Optional Tools**

```text
Please help me install pandoc, ripgrep, jq, and ImageMagick, and then install yt-dlp using uv.
Skip any that are already installed, tell me the reason if any fail, and finally list the version of each tool.
```

## 03 Office Document Processing

Folder: `03-ai-workshop-office-skills/`
Before starting, install the `docx`, `pdf`, `pptx`, and `xlsx` skills in the terminal (see the unit README for commands). Complete the four examples in order—the output of each step is the input to the next.

**Example 1 (xlsx): CSV → Excel**

```text
Convert example/臺灣採購經理人指數(pmi及nmi).csv into an Excel workbook saved as output/pmi.xlsx:
Put the raw data on the first worksheet, calculate the annual average PMI and NMI on the second worksheet, and add a line chart showing the multi-year trend.
```

**Example 2 (pptx): Excel → Animated Presentation**

```text
Based on output/pmi.xlsx, create a 5-slide presentation saved as output/pmi.pptx explaining the meaning of Taiwan's Purchasing Managers' Index (PMI/NMI), recent trends, and key observations, including charts.

All text must be editable in PowerPoint (do not render text as images).

Lay out each slide's content using cards (rounded rectangles) with the slide title shown immediately. Have the cards appear one by one in sequence: on each click, reveal only the next card with a fade-in animation; hide all cards when the slide starts. Background and decorative elements should not be animated.

Use a slow fade transition between slides, and include speaker notes.
```

**Example 3 (docx): Excel → Word Report**

```text
Based on output/pmi.xlsx, write a Word analysis report saved as output/pmi-report.docx:
Include a cover page, an automatic table of contents, and chapters divided into "Indicator Overview", "Multi-Year Trends", "Recent Year Observations", and "Conclusion".
In "Multi-Year Trends", include the annual average table and the line chart.
```

**Example 4 (pdf): Word → Course Handout PDF**

```text
Convert output/pmi-report.docx to PDF using LibreOffice and save it as output/pmi-report.pdf:
Add page numbers at the bottom of every page and a light gray "Course Handout" ("課堂講義") watermark.
```

(If you don't have LibreOffice, change "using LibreOffice" to "using Word".)

## 04 Voucher OCR to Excel: Build Your Own Skill

Folder: `04-ai-workshop-voucher-ocr/`
To experience Steps 1–5 from scratch, move `.claude/skills/voucher-to-excel` elsewhere first, or prepend "Do not use any skill yet" to each prompt.

**Step 1: Let AI Understand the Task First**

```text
First copy record.example.xlsx to record.xlsx. There are five invoice PDFs in the example_deid folder. Please take a look at what fields need to be filled in the Excel file and check whether they can be found in the PDFs.
```

**Step 2: Agree on Highlighting Rules**

```text
Keep the columns even if data is missing: highlight missing fields in bright yellow, highlight uncertain fields with a light blue background, and add a cell comment explaining the reason. Also find a suitable spot at the top of the Excel sheet to add a legend explaining what these two colors mean.
```

**Step 3: Process One Record First**

```text
Just process the first file example_deid/SKM_650i25101515330_deid.pdf for now so I can verify that it is correct.
```

**Step 4: Fill in the Remaining Four Records**

```text
I checked the first record and it looks good. Please fill in the remaining four PDFs into record.xlsx following the same rules, list the results when done, and explain the reason for each yellow or blue cell.
```

**Step 5: Turn the Workflow into a Skill**

```text
Later I will upload new PDF invoices and receipts, and I want to simply say "Please help me enter these records into Excel" and have you automatically follow today's workflow. Please package the procedure we confirmed today into a skill, including where to read each field from the PDF, the yellow and blue highlighting rules, and how to cross-check the amounts. Also give this skill a name and show me a few example phrases I can use to invoke it.
```

**Step 6: Open a New Chat and Finish in One Sentence** (delete `record.xlsx` first)

```text
There are five new invoice PDFs in example_deid, please help me enter these records into Excel
```

Other ways to phrase it:

- "New receipts have arrived—process one first for me to check, and do the rest if it looks good."
- "Enter all the PDFs in example_deid that haven't been logged yet."
- Type `/voucher-to-excel` directly.

**Refine Rules via Conversation**

```text
Why are the invoice buyer titles all highlighted in blue? The buyer for this batch of practice data is "財團法人未來科技研究院智慧雲端運算中心" with Tax ID 81924865. Please add this to the skill's rules so it doesn't need to be highlighted in blue anymore.
```

```text
The blue cells all look right to me—why were you uncertain about them?
```

**Bonus: One Agent Does the Work, Another Audits** (delete `record.xlsx` first)

Gemini does the extraction:

```text
First copy record.example.xlsx to record.xlsx
Please recognize example_deid/SKM_650i25101515330_deid.pdf example_deid/SKM_650i25101515331_deid.pdf example_deid/SKM_650i25101515340_deid.pdf example_deid/SKM_650i25101515341_deid.pdf example_deid/SKM_650i25101515350_deid.pdf and fill them into record.xlsx
```

Claude audits the result:

```text
I have extracted the invoice contents from SKM_650i25101515330_deid.pdf, SKM_650i25101515331_deid.pdf, SKM_650i25101515340_deid.pdf, SKM_650i25101515341_deid.pdf, and SKM_650i25101515350_deid.pdf in example_deid/ into record.xlsx. Please cross-check the PDFs against the Excel sheet and verify whether everything is accurate.
```

## 06 Research Paper Workflow

Folder: `06-ai-workshop-research-papers/` (reference answer in `06-ai-workshop-research-papers-answer/`)

**Step 1: Read the Research Brief**

```text
Please read manuscript/00-research-brief.md, cross-check the numbers against data/tables/, and explain in plain language: what questions this paper aims to answer, what the answers are, what limitations exist, and what literature we need to search for.
```

**Step 2: Search Literature and Build the Library**

```text
Please use the arxiv skill to search for relevant papers based on the search keywords in manuscript/00-research-brief.md, list the candidates for me to choose from, mark the most recommended ones with ★, and do not download them yet.
```

```text
Please use the paper-library skill to ingest all the ★ recommended arXiv papers.
```

(You can also say "Ingest papers 1, 3, and 5"; if irrelevant papers are mixed in, ask AI to "search again using syntax like `abs:microbiome AND abs:longitudinal`".)

```text
Please use the paper-library skill to register the 4 papers—Taur 2018 original clinical trial, QIIME 2, DADA2, and SILVA—by DOI.
```

**Step 3: Write Reading Notes and a Literature Matrix**

```text
Please read every paper in papers/ and write a note for each in library/notes/, including verbatim quotable passages and page numbers. For DOI-only papers without a PDF, read the abstract instead and mark the note as "Abstract Only".
```

```text
Based on the notes in library/notes/ and the study limitations in manuscript/00-research-brief.md, compile a literature comparison matrix showing what prior work did and what our analysis lacks, and save it as library/literature-matrix.md.
```

**Step 4: Write the Paper Section by Section** (review each section before moving to the next)

```text
Please use the arxiv-preprint skill to scaffold an English manuscript in manuscript/, with one file per section inside sections/.
```

```text
Referring to the research-paper-writing skill, write the Methods section in English.
```

```text
Please write the Results section—describe only the data without interpretation. Redraw the required figures from data/tables/.
```

```text
Please write the Introduction section.
```

```text
Please write the Discussion section based on the literature comparison matrix, including study limitations and Conclusions.
```

```text
Please write the structured Abstract.
```

```text
Please propose 3 candidate titles and explain which one you recommend.
```

```text
Adopt candidate title 1. Please fill in the final Declarations section, leaving Author Contributions, Conflicts of Interest, and Funding as placeholders for the authors to complete.
```

**Step 5: Verify Citations and Compile PDF**

```text
Please use the arxiv-preprint skill to check and compile the manuscript, and tell me the results.
```

If LaTeX is installed locally, you can also say:

```text
Please check for local LaTeX using which pdflatex first, then compile manuscript/main.tex directly with local pdflatex + bibtex to produce main.pdf. Fix any errors and recompile, then tell me how many pages the PDF has and whether there are any warnings.
```

```text
Please verify every citation in the manuscript sentence by sentence to confirm whether the original source supports the claim, and cross-check every number in the manuscript against data/tables/. Summarize the results in manuscript/citation-check.md.
```
